## 本次发现并修复

- 旧 `/x/web-interface/view/detail` 和 `/x/web-interface/view` 在本机网络返回 HTTP 412。增加 `/x/web-interface/wbi/view` 基础详情备用路径；附加的观看记录不可用时仍可进入详情。
- 清晰度切换后异步的 readyToPlay 回调会偶发自动播放：将自动播放抑制绑定到新 AVPlayerItem，并避免重复应用最初的历史播放位置。
- 未扫描轮询遇到错误时没有回调、二维码加载失败没有可见反馈、旧二维码响应覆盖新二维码、搜索响应过期等问题。
